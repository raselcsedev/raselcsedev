### 🔍 CareerCraft — In Depth

> A production-grade, fully deployed full-stack SaaS application demonstrating end-to-end ownership from database design to cloud deployment.

**What it does:**

- 📝 **CV Builder** — Choose from 6 professional templates (Classic, Modern Corporate, Minimal, Creative Accent, Developer Technical, Student Graduate). Edit 8 content sections: Personal Info, Summary, Experience, Education, Skills, Projects, Certifications, and Languages. Customise primary colour, font, spacing, and section order with a live preview panel.
- 📥 **CV Import** — Upload a PDF or DOCX file; the backend parses and extracts structured data to pre-fill the editor automatically.
- 📄 **A4 PDF Export** — Browser-native print with a custom `@media print` stylesheet — clean, watermark-free, no paid plan needed.
- 🔄 **CV Duplicate** — One-click clone of any CV for creating role-specific variants.
- 🌐 **Portfolio Builder** — Create a personal portfolio site with a unique public URL (`/p/your-slug`). Add unlimited projects with title, description, tech tags, live URL, repo link, and cover image. Publish / unpublish with a toggle.
- 👤 **Reusable Profile** — Store name, headline, bio, phone, city, socials once. Every new CV and portfolio auto-seeds from it.
- 🛡️ **Role-Based Access** — `USER` (all personal CRUD) and `ADMIN` (system stats, template activation/deactivation). Enforced via JWT claims + NestJS `RolesGuard`.
- 🔒 **Secure Auth** — bcrypt password hashing, HTTP-only `secure` `SameSite=None` JWT cookies, server-side ownership checks on every resource.
- 🌙 **Dark / Light Mode** — System preference + manual toggle across the entire dashboard.
